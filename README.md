# Meu Aprendizado em Python

Repositório com meus estudos e projetos do curso **QApitão Python - Indo Além do Básico**.

## O que Aprendi

Neste curso, desenvolvi habilidades essenciais em Python:

- **Variáveis** - Como armazenar e manipular dados
- **Input/Output** - Interagir com o usuário através de entrada e saída
- **Operadores** - Realizar cálculos e comparações
- **Estruturas Condicionais** - Tomar decisões com if, elif e else
- **Loops** - Repetir ações com for e while
- **Listas** - Trabalhar com coleções de dados
- **Dicionários** - Organizar dados com chave-valor
- **Funções** - Reutilizar código através de funções def
- **Classes e OOP** - Introdução à programação orientada a objetos

## Como Rodar os Arquivos

Para executar qualquer arquivo Python, abra o terminal na pasta do projeto e use o comando:

```bash
python <nome_do_arquivo>.py
```

### Exemplos:

```bash
python variaveis.py
python inputs.py
python funcoes.py
python banco.py
python miniProjeto2.py
```

Alguns arquivos podem solicitar entrada do usuário. Basta digitar os dados conforme solicitado e pressionar Enter.
